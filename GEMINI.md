# Reglas de Trabajo - ElectroFrioV2

## Control de Versiones (Git)
- **NO HACER COMMITS NI PUSH AUTOMÁTICOS:** El asistente NUNCA debe ejecutar `git commit` ni `git push`.
- Todos los cambios de código deben permanecer en el árbol de trabajo local (unstaged / working tree) para que el USUARIO los revise manualmente (con `git diff` / `git status`) y realice sus propios commits.
